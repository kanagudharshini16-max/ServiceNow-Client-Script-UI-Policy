# Requirement Analysis

Project: Implement Client Script & UI Policy (Incident)

## Functional Requirements

1. Create a UI Policy for High Impact incidents.
2. Make the Assignment Group mandatory when Impact is High.
3. Make the Urgency field read-only for High Impact incidents.
4. Automatically set Urgency to High when Impact is High.
5. Prevent saving a High Impact incident when Assigned To is empty.
6. Prevent State changes through list editing.
7. Allow State changes through the Incident form.

## Tools and Platform

- ServiceNow Developer Instance
- Incident Management
- UI Policy
- UI Policy Action
- Client Script
